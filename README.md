### 👋 About Me

I'm a final-year B.Tech Information Technology student at Parul University (Diploma-to-Degree pathway), graduating in May 2027. I'm building toward a career in **cloud security** — with a focus on AWS identity and access management, threat detection, and security automation.

My approach is hands-on: I build small, working security tools (honeypot simulations, IAM misconfiguration scanners, detection pipelines) to understand how cloud attacks and defenses actually work, rather than only studying theory.

**🎯 Open To:** Internship and entry-level roles in Cloud Security, IAM Engineering, and Cybersecurity/SOC Analysis — India-based or remote-eligible.
